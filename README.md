# 📊 Mutual Fund Analytics Dashboard

**Data Analyst / BI Analyst Portfolio Project | Financial Analytics | Power BI Dashboard | Excel Modeling**

An end-to-end financial analytics project analyzing 20 mutual funds across Equity, Debt, and Hybrid categories. The dashboard presents fund performance metrics, risk-return profiles, and comparative analysis to support investment decision-making and portfolio analysis.

---

## 🎯 Business Problem

Investors and fund managers need clarity on:
- Which mutual funds deliver strong long-term returns relative to risk
- How fund performance compares across categories (Equity, Debt, Hybrid)
- What impact expense ratios have on net returns
- Risk-return profiles across different fund types and sizes

This project addresses these questions through comprehensive financial analysis and interactive dashboarding.

---

## 📂 Dataset Overview

- **Funds Analyzed:** 20 mutual funds
- **Categories:** Equity, Debt, Hybrid
- **Fund Types:** Large-cap, Mid-cap, Small-cap, Sectoral, Liquid, Balanced
- **Time Period:** Q1 2020 to Q1 2025
- **Key Data Points:** NAV, Returns, Expense Ratio, Market Cap, Fund Size

## 📊 Data Cleaning & Transformation Process

**Steps performed:**
1. **Data Consolidation** — Imported fund data from multiple sources into a single Excel model
2. **Financial Data Validation** — Verified NAV trends, returns, and expense ratio calculations
3. **Time Period Standardization** — Aligned all funds to Q1 2020–Q1 2025 quarterly data
4. **Power Query ETL** — Created a refreshable transformation workflow for dashboard-ready analysis
5. **Derived Metrics** — Calculated CAGR, Sharpe Ratio, Jensen's Alpha, and Beta values

**Result:** Clean, validated financial dataset ready for analysis and visualization

## 📈 Key Financial KPIs & Calculations

| KPI | Definition |
|-----|-----------|
| **NAV (Net Asset Value)** | Fund's per-unit market value over time |
| **1Y / 3Y / 5Y CAGR** | Compound Annual Growth Rate for respective periods |
| **Sharpe Ratio** | Excess return per unit of risk taken |
| **Jensen's Alpha** | Risk-adjusted excess return vs. benchmark |
| **Beta** | Fund volatility relative to market benchmark |
| **Expense Ratio** | Annual fund management cost as % of AUM |
| **Standard Deviation** | Measure of fund volatility |
| **Return vs. Expense Impact** | Net return after expense ratio deduction |

---

## 🔍 Key Insights

- **Category Performance Gap:** Equity funds showed stronger long-term return potential compared to debt funds, while also carrying higher volatility.

- **Expense Ratio Impact:** Higher expense ratios demonstrated a negative correlation with net returns, indicating the importance of cost efficiency.

- **Risk-Return Profile:** Equity-oriented funds showed higher return potential with higher volatility, while debt funds offered more stable performance.

- **Fund Consistency:** Funds with positive Jensen's Alpha outperformed market benchmarks on a risk-adjusted basis.

---

## 💡 Investment & Business Insights

1. **Category Selection** — Understand that equity funds suit long-term wealth creation while debt funds provide stability
2. **Expense Ratio Awareness** — Lower expense ratios positively impact net returns; prioritize cost-efficient funds
3. **Risk Assessment** — Beta and Standard Deviation help identify funds aligned with risk tolerance
4. **Diversification Value** — Hybrid funds provide balanced risk-return profiles for moderate investors
5. **Performance Metrics** — Use Sharpe Ratio and Alpha to identify truly superior performing funds
